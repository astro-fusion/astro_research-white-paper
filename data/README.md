# data/

The single data root for the repository (`DATA_ROOT` in `studies/_paths.py`).
Nothing under `raw/`, `processed/` or `snapshots/` is committed; files are
fetched from their source or generated by scripts. `make check-data` prints the
SHA-256 hash and row count of every required input.

| Folder | Contents |
|---|---|
| `raw/` | Files exactly as downloaded |
| `processed/` | Files derived from raw data (for example `aligned_planetary_data.csv`, read by `scripts/generate_artifacts.py`) |
| `snapshots/` | Frozen inputs of a published result; each is published as a release asset and its SHA-256 recorded below |
