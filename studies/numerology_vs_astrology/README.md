# Numerology versus astrology

**Question.** Date numerology assigns one ruling planet per calendar day; the
Moon's nakshatra lord changes roughly every day as well. Do the two systems
name the same planet more often than chance, and how do their time series
compare (correlation, spectrum, alignment windows)? A secondary dataset tests
name and birth-date numerology on an athlete sample.

**Status.** Figures and statistics are being recomputed after the sidereal
correction (see [CORRECTIONS.md](../../CORRECTIONS.md), item c).

## Contents

- `paper/NUMEROLOGY_ASTROLOGY_TEMPORAL_DISCONTINUITY.qmd` with `paper/sections/`.
- `paper/numerology_planet_timeline.qmd`: planetary strength versus numerology over time.
- `paper/drafts/`: superseded drafts kept for their unique text; not rendered.
- `scripts/`: catalogue, daily metrics, name and personal metrics, athlete sample, temporal, correlation and spectral analyses.
- `figures/`, `tables/research_results.json`.

Numerology calculations come from the `vedic_numerology` package in `libs/`
(`vedic_numerology.numerology`); there is no study-local copy.

## How to run

```bash
pip install -e ".[dev]"
python studies/numerology_vs_astrology/scripts/generate_numerology_catalog.py
python studies/numerology_vs_astrology/scripts/generate_numerology_metrics.py
python studies/numerology_vs_astrology/scripts/fetch_athletes_sample.py
python studies/numerology_vs_astrology/scripts/generate_name_numerology_metrics.py
python studies/numerology_vs_astrology/scripts/compute_athlete_name_birth_correlation.py
python studies/numerology_vs_astrology/scripts/generate_temporal_analysis.py
python studies/numerology_vs_astrology/scripts/correlation_analysis.py
```

## Data

`data/` is gitignored; every file in it is generated by the scripts above or
fetched (`athletes_sample.csv` is sampled from the stat408 athletes dataset on GitHub; see `fetch_athletes_sample.py`).
